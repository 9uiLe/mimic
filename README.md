# Mimic

デジタルUIに関するデザインの知識・概念・思想・哲学を言語化し、人とAIが理解できるように説明する知識データベースです。Web、iOS、Androidなどに共通する考え方を扱います。

## 知識を読む

AIは[知識の入口](knowledge/README.md)から必要な概念の `KNOWLEDGE.md` を読み、版・採用状態と対象範囲を確認します。必要に応じて本文から出典や説明例へ進みます。索引だけを本文の代わりにしません。

## 人向けの閲覧

[GitHub Pages](https://9uile.github.io/mimic/)では、収録した概念の一覧から本文・関連概念・出典・例をHTMLで読めます。Markdownの原文も参照できます。

## Repositoryの保守

内容・機能・運用を変更または点検するときは、[Repositoryの方針と利用ガイド](guideline/README.md)、[AI向けの作業ガイド](guideline/ai.md)、[知識の構造ガイド](guideline/knowledge-structure.md)、[開発・公開ガイド](guideline/development.md)を参照します。
