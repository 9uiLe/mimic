# Gen Interface JP 0.8.0 for Mimic Pages

Mimic installs the exact `gen-interface-jp` npm release `0.8.0`, then copies its unmodified normal-family `400.css`, `600.css`, 128 WOFF2 subsets per weight, and `OFL.txt` into the Pages artifact. The package is available at <https://www.npmjs.com/package/gen-interface-jp/v/0.8.0>; its SHA-512 package integrity is `sha512-7rIytSAfuugVjYithrQseT0zqeUIkJd0LY3Ugdfbk/FxzMSeagcskeZlof5uWJ5liW3Zhn7pdLHq2OIvAftx+A==` and is pinned in `bun.lock`.

`integrity.json` records the per-file SHA-256 hashes and sizes from the version-pinned jsDelivr npm mirror, <https://cdn.jsdelivr.net/npm/gen-interface-jp@0.8.0/>. The installed package was checked against all 259 entries. The Pages build repeats that check before publishing 6,917,097 bytes of font assets. This README and `integrity.json` are tracked build inputs and are not published by Mimic Pages.

The font files are licensed under SIL Open Font License 1.1. The package's original `OFL.txt` is published alongside the font files. The project source code uses a different license; see the [upstream release description](https://github.com/yamatoiizuka/gen-interface-jp/blob/v0.8.0/README.ja.md).
