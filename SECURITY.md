# Security reporting

Mimic is in pre-release development. Please report suspected vulnerabilities privately where a private channel is available. Do not put exploit steps, secrets, private data, or an unpatched vulnerability's details in a public issue or pull request.

1. Check the repository's **Security** tab for a **Report a vulnerability** option. Use it if it is available; its presence depends on repository settings.
2. If that option is unavailable, open a public issue only to request a private reporting channel from the maintainer. Keep the issue free of vulnerability details. Wait for a private channel before sharing technical details.
3. In the private report, include the affected revision or version, impact, reproduction steps or proof of concept, and any mitigation you know. Do not include credentials or personal data unless essential and safe to share.

The maintainer handles triage and disclosure decisions for this pre-release project. There is no promised response or fix time. For ordinary bugs without sensitive security details, use the [bug report template](.github/ISSUE_TEMPLATE/bug_report.yml).
