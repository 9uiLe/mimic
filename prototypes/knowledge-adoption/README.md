## 目的と完成条件

既存の概念を意味・背景・出典に沿って説明し、人が正式採用の可否をレビューできる本文をそろえる。独自の設計手順・表示案の優劣・効果の予測を知識本文へ持ち込まない。

確認するのは、出典との対応、概念の違い、対象範囲、説明用の例の位置づけ、３件間の用語と参照の整合である。画面の試作や利用者による効果測定は、この本文の採用条件に含めない。

## 確認の状況

作成担当が各本文に対応する原典・公式資料の該当節を照合し、主担当が３本文と照合記録を読んだ。本文には、出典の立場・範囲と、説明用に作成した整理や例を明示している。

別文脈の担当が、ユーザー原文から確認観点を再構成した後、３候補を読み、出典の主張・編集上の整理・説明例を読み分けた。重要な指摘はなかった。「判断材料の選定」を単一の理論や手順として読む誤り、グルーピングの三つの役割の混同、視覚的な強調と業務上の優先度の混同も読み取らなかった。

読解担当は、疑義が生じた概念モデルと視覚的表現についてNorman、Fluent 2、W3C 1.3.1の該当箇所を照合し、修正必須の不一致は見つけなかった。全出典を独立に再照合した結果ではない。主担当は３本文とこの報告を照合し、文章の採否を人がレビューする段階へ進められると判断した。

主担当は本文のメタデータ、３件間の相対リンク、Markdownの形式も確認した。本文の正確さと、生成・公開機能の動作は、別の対象として確認する。

## 現行から変えたこと

AIの入力・出力、独自の判断手順、Mimicの５軸、仕事一覧の具体的な採用案、実画面の実験計画を、既存知識の説明から分けた。例は概念を説明する短いものへ置き換えた。

「判断材料の選定」は一つの既存理論名として扱わず、複数の考え方を紹介する題目として明示した。グルーピングと視覚的な優先順位の区別も、原典が提唱した共通の分類ではなく、説明のための整理として記述した。

## 残ること

- 人による３本文の内容レビューと採否の判断。
- 採用が決まった本文の正本への反映、版・状態と入口文書の更新。

このフォルダーはGitHub上でレビューするための編集資料であり、GitHub Pagesの配信対象には含めない。本文の採否レビューと、正本・公開ページへの反映を分けて扱う。
