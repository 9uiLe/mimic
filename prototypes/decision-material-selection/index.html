この案内について

#

利用者が判断に使う情報の内容と提示の仕方を考えるために、関連する知識へ進む案内です。「判断材料の選定」は複数の考え方を扱う題目であり、一つの理論の名称ではありません。各概念の定義・背景・対象範囲は、リンク先の KNOWLEDGE.md と、そこから参照する出典・説明例で読みます。この案内が、それらの本文をまとめて置き換えるものではありません。

情報の内容と表現

#

Ecological Interface Design（EID）は、複雑な人間機械システムで情報の内容・構造と表現を考える枠組みを説明します。一般のUIで表示項目を減らす手順や、適切な項目数の理論としては扱いません。

外部の情報と、その意味の理解

#

外的表象は、図や配置など外部環境にある情報と、内部と外部に情報が分散する認知課題との関係を説明します。概念モデルは、構成要素を結び、仕組みと動作の理由を理解する枠組みを説明します。外に情報があることと、その意味を理解できることを区別して読みます。

まとまりと強調

#

グルーピングは、情報をどのような意味のまとまりとして構成し、表すかを扱います。視覚的な優先順位は、提示する情報の相対的な強調や関係の表し方を扱います。情報の内容、まとまり、強調は関連しますが、同じ概念ではありません。

部品に応じて情報を段階的に示す

#

情報を最初からすべて見せず、操作に応じて詳細を示す部品もあります。Carbonのデータテーブル指針のExpandableは、行の展開領域を補足情報や追加の取得時間が必要なデータに使うとしています。展開領域が窮屈なら、専用ページやサイドパネルなども選択肢に挙げています。

GOV.UKのアコーディオン指針のWhen not to use this componentは、隠れた内容に気づかない人や操作を理解しない人がいることを説明し、全員が見る必要のある内容には使わないとしています。

これらは、それぞれの部品で何を隠すかに関する指針です。すべてのUIで常時表示と詳細表示の境界を定める共通規則ではありません。

出典とこの案内の範囲

#

各概念の出典と確認箇所は、それぞれの KNOWLEDGE.md から参照する references/sources.md に記載します。部品の説明は、上記のCarbonとGOV.UKの該当節に基づきます。

概念をつなぐ章立てはMimicの編集上の整理です。複数の出典が、一つの情報選定手法としてまとめて提唱したものではありません。
