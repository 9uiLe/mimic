# 意味付き関係グラフ

概念の説明本文から独立したJSONで、知識間の関係を索引できるようにします。[知識の入口](../knowledge/README.md)から概念を探し、[Pagesの関係グラフ](https://9uile.github.io/mimic/graph/)では関係と根拠から本文へ進めます。読む順序や範囲は、読む人やAIが目的に応じて決めます。

## 正本と役割

| ファイル | 定義するもの |
| --- | --- |
| [graph.json](graph.json) | 全概念のノードと、本文に根拠がある意味付きの辺 |
| [vocabulary.json](vocabulary.json) | 関係型の意味・向き・対称性・推移の規則 |
| `knowledge/<id>/KNOWLEDGE.md` | 概念の定義・背景・範囲・違いの説明 |
| 各概念の `references/sources.md` | 原典と主張の対応、対象範囲と注意 |

関係型と関係文は、本文に基づくMimicの編集上の整理です。原典に共通する正式な分類や新しいデザイン理論として扱いません。構造化した関係の定義元はこのディレクトリのJSONです。本文のfrontmatterは識別情報・版・範囲を保持し、関係を重複して定義しません。本文内の関係の説明は人向けの文脈として残します。辺はその説明を根拠に分類し、本文の定義をグラフの形へ合わせて変更しません。

## データを読む

`graph.json` の `nodes` は `id`・`title`・`path`・`version`・`sha256` を持ちます。`path` はRepositoryルートからの本文パス、`sha256` はその本文全体の指紋です。本文を取得するときや、グラフがどの版を参照しているかの確認に使います。

`edges` の各辺は `id`・`from`・`to`・`type`・`statement`・`evidence` を持ち、必要な場合は `scope` で適用範囲を限定します。`evidence` の各要素は `concept`・`heading`・`quotation` で、根拠にした本文の概念ID・見出し・引用を示します。引用だけで文脈を判断せず、必要な本文と出典を確認します。

`type` は `vocabulary.json` の `types` に定義された関係型を参照します。型の `description`・`directed`・`transitive` と補足条件を確認し、階層・依存・関連・対比などを同じ意味として扱いません。型のラベルだけから全体と部分、上位と下位、前提と利用先を推測しません。

方向がある辺は `from` から `to` へ読みます。逆参照で見つけた辺も、元の向きを維持します。対称な型は語彙の定義に従います。経路がつながることだけで新しい関係を確定せず、推移は型の定義と各辺の範囲が認める場合に限ります。依存は `statement` と `scope` が述べる処理・説明上の範囲に限り、概念全体の必読条件や読書順序へ広げません。

`transitive: false` は推移規則を採用しないという意味です。AからB、BからCへの辺からAとCの関係を導けず、AとCが無関係であるとも主張しません。

関係の未記載は無関係を意味しません。根拠のない階層・依存を網羅するために補いません。ノードの配置・距離・色にも、語彙にない意味を与えません。

## AIによる索引

JSONは本文を連結せずに読めます。AIは関係型・入出力の辺・根拠・本文の版を使って自由に索引し、必要な範囲を判断できます。たとえば、ある概念に接続する辺を抽出できます。

```sh
jq '.edges[] | select(.from == "color-contrast" or .to == "color-contrast")' relations/graph.json
```

抽出結果は読む候補と確認箇所を示します。説明に使う本文の定義・対象範囲と必要な出典・例を実際に読み、グラフの探索を本文の確認済みという報告へ置き換えません。

## 更新する

本文や根拠を変更したら、辺の意味・型・方向・範囲と引用を再照合します。再照合後に `bun run relations:sync` でノードの本文メタデータとSHA-256を同期し、`bun run relations:check` で検査します。同期コマンドは意味辺を修正せず、検査の成功は関係の意味の正しさを保証しません。

本文の全文ハッシュが変われば鮮度の再確認が必要です。機械検査で参照・引用が一致しても、主張の意味と文脈が保たれているかは別に確認します。新しい関係型や概念を追加するときも、本文に根拠があることを確認します。生成・品質検査と公開の許可は[開発・公開ガイド](https://github.com/9uiLe/mimic/blob/main/guideline/development.md)に従います。

未対応のフィールドは同期前に拒否し、元のグラフを変更しません。
