# UIの視覚的なスタイルの出典と説明の範囲

本項目の版は[本文](../KNOWLEDGE.md)で確認します。以下の資料を2026年10月24日に確認しました。

「UIの視覚的なスタイル」は、本項で外観や表情のまとまりを指す対象語です。定義と章立ては、以下の資料が扱う視覚要素・構成・表現の関係を説明するためのMimicの編集です。単一資料からの引用定義でも、複数組織に共通する確立理論でもありません。

| 本文の主張 | 出典と該当箇所 | 範囲・留意点 |
| --- | --- | --- |
| 視覚デザインは線・形・色・グリッド・空間などの組み合わせを扱う。読み取りや操作、感情、ブランドの知覚に関わる。 | [Kelley Gordon — 5 Principles of Visual Design in UX、Introduction / Why Visual-Design Principles are Important](https://www.nngroup.com/articles/principles-visual-design/) | NN/Gの著者による2020年の解説。確認時は2026年9月1日の最終レビュー表記。要素の構成を説明する著者の解説として参照し、個別UIの成果を保証しない。同記事の五原則をスタイルの正式な五分類にはしない。 |
| 人の必要性を優先し、有用性と喜びを両立する。装飾には目的と意味があり、機能と表現を釣り合わせる。 | [Adobe Spectrum — Principles、Human / Focused](https://spectrum.adobe.com/getting-started/principles) | Adobeの製品制作を導く価値と指針。視覚・インタラクション以外にも適用する原則であり、全UIの客観的な評価尺度ではない。 |
| 固定要素による統一感と、流動的な表現による独自性を共存させる。 | [IBM Design Language — Principles、Uniquely Unified](https://www.ibm.com/design/language/philosophy/principles/) | IBM名義のデザインを対象とする原則。すべての製品に同じ固定要素や独自性の程度を求める規格ではない。 |
| productiveとexpressiveは描画方法と用途が異なる。expressiveは奥行き・動きの印象を作り、必要な場面で選択的に使う。UIアイコンの代わりにはしない。 | [IBM Design Language — Pictograms、Usage / Productive versus expressive](https://www.ibm.com/design/language/iconography/pictograms/usage/)。用語の補足は、概念や題材を表す図記号について[Pictograms、Design冒頭](https://www.ibm.com/design/language/iconography/pictograms/design/)、操作や機能を示す用途について[UI icons、Usage冒頭 / Color](https://www.ibm.com/design/language/iconography/ui-icons/usage/)を参照。 | IBMのピクトグラムに関する公式例。動きの印象は絵の表現についての説明で、アニメーションの仕様ではない。二つの名称を全UIの分類へ一般化しない。本文ではこの使い分けの記述を確認し、画像自体の比較や知覚実験は行っていない。 |
| 色・余白・文字などの広い値の範囲から、限定した選択肢をDesign Tokenとして用意する。 | [USWDS — Design tokens、冒頭 / Introducing design tokens](https://designsystem.digital.gov/design-tokens/) | USWDSの視覚デザインの構成と共有に関する説明。DTCG交換形式の定義や、すべてのシステムに必須のToken構造ではない。 |

本文の「目的と視覚表現の関係」の表、印象語だけでは具体的な選択が確定しないことの説明、[表現の選択理由の例](../examples/style-rationale.md)は、これらを読むためのMimicの整理・作例です。効果を検証した手順や、原典にある分類としては扱いません。

既存のTypography・余白・階層・色の文脈などの定義と出典は、[本文の関連概念](../KNOWLEDGE.md#関連する概念と境界)から各 `KNOWLEDGE.md` と補足へ進みます。ここに複製した独立の定義は置きません。

特定の形容から色値・角丸・書体が一意に決まること、作例が意図した印象を利用者に与えること、日本語のWeb・スマホUI全般への効果は、今回の資料確認では確定していません。
