# HEARTと目標・シグナル・指標の出典

確認日は2026年10月25日です。

Kerry Rodden、Hilary Hutchinson、Xin Fuによる2010年の論文、Measuring the User Experience on a Large Scale: User-Centered Metrics for Web Applicationsを参照します。
[Google Researchの書誌情報](https://research.google/pubs/measuring-the-user-experience-on-a-large-scale-user-centered-metrics-for-web-applications/)と、[Google配布の著者版PDF](https://research.google.com/pubs/archive/36299.pdf)を確認しました。

| PDFの確認箇所 | 本文との対応 |
| --- | --- |
| 1頁 INTRODUCTION | 大規模Web製品の実務という背景 |
| 2頁 RELATED WORK、HEART METRICS | 調査との補完関係、カテゴリの枠組み、全カテゴリは必須でないこと |
| 2～3頁 Happiness、Engagement、Adoption and Retention、Task Success | 各カテゴリの意味 |
| 3～4頁 Goals-Signals-Metrics | 目標・兆候・指標、別要因への注意、正規化と記録条件 |

日本語の表は論文の要約です。論文中の製品事例や数値を、他の製品への推奨値にはしていません。
関連概念への接続はMimicの編集上の整理です。
PDFの複製はRepositoryに含めません。
