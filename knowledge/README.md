# 知識の入口

デジタルUIに関するデザインの知識・概念・思想・哲学の本文を置きます。AIが参照するときは、この索引から必要な本文を読みます。

## 読む本文

| ID | 正本 | 説明すること |
| --- | --- | --- |
| `decision-material-selection` | [判断材料の選定](decision-material-selection.md) | 判断に必要な情報、その表現、文脈や提示方法に関する考え方 |
| `grouping` | [グルーピング](grouping.md) | 意味上の分類、近接によるまとまり、名称や見出しの役割 |
| `visual-hierarchy` | [視覚的な優先順位](visual-hierarchy.md) | 相対的な強調、内容の階層、業務上の優先度の違い |

各本文が、定義、背景、概念同士の違い、対象範囲、出典の正本です。[RepositoryのREADME](../README.md)やこの索引は、本文を参照した代わりにはなりません。

## 参照する前に

本文先頭の `id`・`title`・`status`・`version`・`scope`・`related` を確認します。現在の３文書は `status: proposed`、`scope: general-digital-ui` です。`proposed` はMimicにおける説明文の採用前の状態を表し、説明する既存の概念そのものを未確定の仮説とする意味ではありません。

使う概念の定義だけでなく、出典の立場と対象範囲、関連概念との違い、説明用の整理や例の位置づけまで読みます。利用者や案件の条件に適用するときは、本文が説明する知識と、案件固有の仮定・提案を区別します。必要な知識がない場合は、その不足を明記します。

実際に読めた本文と版を確認します。索引・題名・リンクだけを受け取った場合や、本文を取得できなかった場合に、参照済みとは報告しません。本文を読めたこと、内容を適切に適用できたこと、実画面の使いやすさを確かめたことは、それぞれ区別します。

## 閲覧・編集の案内

「判断材料の選定」の[人向け閲覧ページ](../prototypes/decision-material-selection/index.html)と[AI向け全文](../prototypes/decision-material-selection/ai.md)は、正本から生成します。内容の編集は正本で行い、生成物を直接編集しません。他の２件は本文Markdownを参照します。

掲載・編集・採用の方針は[Repositoryの方針と利用ガイド](../guideline/README.md)、AIの作業は[AI向けの作業ガイド](../guideline/ai.md)に従います。生成物の更新方法と公開手順は[開発・公開ガイド](../guideline/development.md)を参照します。
