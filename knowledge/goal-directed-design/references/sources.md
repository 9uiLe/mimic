# Goal-Directed Designの出典

## 原典と対応する説明

Alan Cooper、Robert Reimann、David Cronin、Christopher Noesselによる『About Face: The Essentials of Interaction Design』第4版（2014年）を参照します。
[出版社Wileyの第1章抜粋](https://catalogimages.wiley.com/images/db/pdf/9781118766576.excerpt.pdf)の、誌面に印刷された頁番号を示します。

| 本文の説明 | 原典の対応箇所 | 説明の範囲 |
| --- | --- | --- |
| 調査から設計へつなぐ狙い、六段階と方法の組み合わせ | 23–24頁、An Overview of Goal-Directed Design / A process overview | 著者らの方法の概要 |
| ペルソナを、調査に基づく利用者モデルとして説明 | 26頁、Modeling | 行動・目標などをまとめるモデルの概要 |
| ペルソナの目標、コンテキストシナリオ、対象・操作・文脈、事業・技術条件 | 26–27頁、Requirements Definition | 要求を考える観点と条件 |
| 要求から設計要素、スケッチと振る舞いの説明へ | 27頁、Framework Definition | 製品の構成を定義する段階 |
| 主要な経路や各種条件をシナリオで詳しくする | 28頁、Refinement | 詳細化の概要 |

## 説明と例の範囲

この項目は第1章の概要に対応します。第4章・第5章の詳細な実施方法全体を説明するものではありません。
「機能候補」と「コアの選別」の区別や関連概念との比較は、原典を一般化しすぎないための本書の整理です。
本書の読書メモ例にある要求や画面案を、原典に記載された設計として扱いません。
例における「コア機能」は説明用の仮の意味であり、四つの原典に共通する定義ではありません。

概念モデルとの違いは[概念モデルの本文](../../conceptual-models/KNOWLEDGE.md)と、その出典を参照します。
