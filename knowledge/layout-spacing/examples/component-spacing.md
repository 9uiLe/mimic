# 予定一覧の間隔の説明例

架空の業務用予定画面で、「日付の入力欄」と「絞り込みボタン」を同じ操作群に置き、その操作群と予定一覧を別のセクションとして配置します。この画面では、次の相対関係で余白の役割を説明できます。

| 何と何の間隔か | この作例で表す関係 |
| --- | --- |
| 日付入力欄と絞り込みボタンの間 | 同じ操作群として近くに置く |
| 操作群と予定一覧の間 | 別セクションなので、操作群の内側より広く空ける |

予定カード同士の間隔や、画面端と内容の間隔は、さらに別の用途です。すべてを同じ値にする必要があるとは限りません。

表示幅が狭く、入力欄とボタンを横に並べると内容が窮屈になるなら、縦に配置し直す場合があります。その場合も二つを同じ操作群として扱い、操作群と予定一覧との区切りを保つ、という関係は変わりません。画面が広い場合でも、広さに比例してすべての間隔を増やすわけではありません。余白の数値や比率を決めるには、対象の製品と画面条件が必要です。

これはMimicが作成した概念説明用の例です。原典の実験や、特定の画面に採用すべき値、利用者の成果を予測するものではありません。
