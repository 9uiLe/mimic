# 蔵書一覧の内容と操作の層を区別する例

架空のiOSの蔵書一覧を使い、Liquid Glassが表す層と、その下の内容との関係を説明します。
これはMimicが作成した概念説明用の例です。原典の画面や、特定製品の採用案ではありません。

| 対象・場面 | この例で説明する関係 |
| --- | --- |
| 本の表紙、題名、読書状況 | 利用者が読み、選ぶコンテンツ。操作の層との違いを保つ。 |
| 一覧の上に浮くツールバー | コンテンツを覆い尽くさず、操作へ到達する層として捉える。 |
| ツールバーから開くメニュー | 押した操作と開いた内容のつながりを、変化の過程でも考える。 |
| 一覧のスクロール中 | 静止したときと、文字や表紙が操作部品の背後へ入るときを区別する。 |

仮に本の各項目とツールバーの両方へ同じガラス効果を重ねれば、この例で説明する内容と操作の層を区別しにくくする可能性があります。
ガラス面の数を、調和の良さの尺度にはしません。

具体的な画面を作る場合、背景、表示設定、文字サイズや動きの条件を定め、実際の見え方と操作を確認する必要があります。
この例では書体・色・数値・実装APIを指定しておらず、その確認も行っていません。
