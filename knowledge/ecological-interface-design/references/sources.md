# Ecological Interface Designの出典

## 原典と対応する説明

- [Vicente & Rasmussen — Ecological Interface Design: Theoretical Foundations（1992）](https://backend.orbit.dtu.dk/ws/files/158017888/SMC.PDF)：§II.B、§III.A–B。EIDにおける情報内容と表現の区別、抽象化階層とその背景。

本文は、複雑な人間機械システムを対象とする設計枠組みとして説明しています。原典から、一般のデジタルUIに共通する情報削減の手順や適切な表示項目数を導いていません。外的表象との関連づけは本書の説明上の整理であり、この原典における理論の分類として示したものではありません。
