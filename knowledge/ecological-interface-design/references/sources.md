# Ecological Interface Designの出典

## 原典と対応する説明

[Vicente & Rasmussen — Ecological Interface Design: Theoretical Foundations（1992）](https://backend.orbit.dtu.dk/ws/files/158017888/SMC.PDF)を参照します。DTU掲載の査読版で、以下の頁番号はPDFの通し番号ではなく原稿に印刷された頁番号です。

| 本文の説明 | 原典の対応箇所 | 説明の範囲 |
| --- | --- | --- |
| 複雑な人間機械システムを対象とするEID | Abstract、§I、1–3頁 | 著者の枠組みの対象 |
| 情報の内容・構造と表現の区別 | §II.B、5–6頁 | 設計問題の構成 |
| 抽象化階層と目的・手段の関係 | §III.A、7–8頁 | 同じ領域の異なる抽象度。階数と内容は領域により異なる |
| 想定外の異常への対応と作業領域の制約 | §III.B、8–9頁 | 原典の背景と目的 |
| SRKの区別と三つの水準への支援 | §II.B、6頁、§IV、13–14頁、§IV.E–V.A、21–22頁 | 抽象化階層と組み合わせる枠組み、EIDの目標 |

一般のデジタルUIに共通する情報削減の手順や適切な表示項目数を導かないことは、本書の説明範囲の限定です。外的表象との関連づけは本書の説明上の整理であり、この原典における理論の分類として示したものではありません。
