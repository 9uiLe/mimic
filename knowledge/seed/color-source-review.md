# Color decision source review

Reviewed 2026-10-09. Public first-party sources; original paraphrases only.
Speaker Deck images were acquired selectively using `speakerdeck-knowledge`
guidance and were inspected without bundling them. Browser checks were made in
the user's Mac Chrome. Observation supports the source's own process; Mimic
transfer is unverified.

| Case                                                                                                                                                                                                 | Author and verification scope                                                                                                                    | Observed decision and limit                                                                                                                                                                                                                 | Mimic transfer hypothesis                                                                                                                |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| [kintone Style Book](https://speakerdeck.com/kintone/kintone-style-book)                                                                                                                             | Cybozu / kintone; 41-slide transcript and actual images for slides 24, 26, 28 inspected.                                                         | Slide 24 connects core yellow to Warm Smart; 26 contrasts yellow-led with support-color dominance and muddy/dark alternatives; 28 contrasts readable/weak yellow pairings. The deck is guidance for kintone, not evidence for Mimic yellow. | Derive core color prominence from a stated brand character, then test broad vs restrained use on target screens.                         |
| [YouTube’s New Hue](https://design.google/library/youtube-new-red-color)                                                                                                                             | YouTube art/design team: Robyn Lee, Amy Yip, Jessie Zo, David Amichai, Tom Moran, Linda Hong; article, gradient figure, and rationale inspected. | Research identified dated color; the team retained recognizable red but cooled it, compared adjacent gradient hues, and limited use to marks and signature UI moments. Product effects claimed in this article are not Mimic outcomes.      | Compare selective brand emphasis against a broader warm core; avoid importing red, magenta, or a gradient without approved brand intent. |
| [SmartHR color tokens](https://smarthr.design/products/design-tokens/color/)                                                                                                                         | SmartHR Design System; semantic token documentation for text, background, surface, border, main, warning and danger read.                        | Roles separate palette purpose from component placement. The source does not decide Mimic's values or status vocabulary.                                                                                                                    | Define role map and inspect state/color collisions before proposing hex values.                                                          |
| [Carbon color guidelines](https://www.carbondesignsystem.com/building-blocks/foundations/color/guidelines) and [tokens](https://www.carbondesignsystem.com/building-blocks/foundations/color/tokens) | IBM Carbon Design System; guidance, token tables, and actual layering/dropdown diagrams inspected.                                               | Base and nested layers pair with field/border tokens; contextual tokens adapt reusable components across layers. Carbon's full four-layer system may be excess for Mimic.                                                                   | Use only needed depth levels for Run panels and proposal detail; retain stable semantic roles across screens.                            |

No paywall, new login, or permission was required. No third-party color values,
screenshots, or artwork are included. Visual legibility examples are recorded
as design observations; they do not become an accessibility evaluation gate in
this Mimic review.
