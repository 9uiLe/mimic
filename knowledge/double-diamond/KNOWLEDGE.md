# Double Diamond

## 概念と背景

Double Diamondは、Design Councilが示すデザインとイノベーションのプロセスモデルです。
2004年に公開されました。
二つのダイヤモンドは、問題や案を広く深く探索する発散と、焦点を絞って行動する収束を表します。
問題を理解する活動と、解決案を考えて試す活動の両方を説明します。

## 四つの活動

以下はDesign Councilによる活動名と、その説明の要約です。

| 活動 | 何を扱うか |
| --- | --- |
| Discover | 影響を受ける人と話し、その人と時間を過ごして問題を理解する |
| Define | 調査で得た理解から、取り組む課題を定め直す |
| Develop | 定めた問題に対する異なる解決案を考え、多様な人と共に作る |
| Deliver | 小さな規模で案を試し、機能しない案を退け、有望な案を改善する |

## 往復するプロセス

Design CouncilのFramework for Innovationは、これを線形の過程ではないと説明します。
新たな理解によって問題の探索へ戻ることも、Discoverの中で初期案を作って試すこともあります。
利用後のフィードバックを受けて改善する活動も続きます。

したがって、四つの名前を一度ずつ通れば設計が完成するという意味ではありません。
Deliverを本番公開の一回の操作だけに置き換えることもできません。
図だけでは、案件の承認条件、担当、期間、本番運用の要件までは決まりません。
