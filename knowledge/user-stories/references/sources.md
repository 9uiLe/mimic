# ユーザーストーリーと受入条件の出典

確認日は2026年10月25日です。

| 公式資料 | 確認箇所 | 本文との対応 |
| --- | --- | --- |
| [GOV.UK, Writing user stories](https://www.gov.uk/service-manual/agile-delivery/writing-user-stories) | What to include、The right format for user stories、Focus on the goal | actor・narrative・goal、形式の選択、目標と機能の必要性 |
| 同資料 | Acceptance criteria、Planning with your user stories | 完了を確認する成果、根拠との接続、会話で詳細を補うこと |
| [GOV.UK, Learning about users and their needs](https://www.gov.uk/service-manual/user-research/start-by-learning-user-needs) | Linking user needs to user stories | ニーズと仕事の単位、具体的な内容、依存関係、追跡可能性 |

GOV.UKが求めるストーリーの利用を、すべての開発組織への義務として一般化しません。
受付番号の例はMimicの作例です。完了条件と実際の評価結果の違いを示し、効果の実証とは扱いません。
要件全体や組織成果との境界、関連概念の接続はMimicの説明上の整理です。
