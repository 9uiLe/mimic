# Experience-first synthetic case

`case.json` is an authored product scenario and mobile direction for 9UI-125. It is not evidence from users or a human design decision. The authored builder input is kept separately in `plan.ts`; it is neither an approved artifact nor an approval of the generated structure. Tests use fixture authority only. The desired mobile transformation is intentionally recorded as unsupported by the current builder contract; a single DOM tree and a column count cannot express its reorder, collapse, replace, or progressive disclosure choices.
