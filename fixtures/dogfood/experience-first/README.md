The authored builder input is kept separately in `plan.ts`; it is neither an approved artifact nor an approval of the generated structure. Tests use fixture authority only. Its optional responsive v1 entry implements the C-204 review view's reorder, collapse, replacement, and progressive disclosure with the existing exact approved responsive-rule lock. The local back-to-overview anchor stays within the review view; queue/review navigation and draft restoration remain 9UI-148 work.
