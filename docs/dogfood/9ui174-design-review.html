4つの構造案

各案は S10 の保存済み成果物に対応します。構造の違いは情報の並べ方、詳細への進み方、同時に見せる量です。

1

検索一覧 / Run index with persistent record context

A searchable index of five saved Runs opens a persistent record detail view that keeps Run identity, task, session, artifact reference, and reported connection status together. A distinct preview route returns to the index and makes no claim of Run provenance.

  • Open a persistent detail pane for the chosen Run while retaining the index and all identifying fields.

2

時系列 / Chronological Run stream with explicit preview return

A dated stream presents saved Run records in sequence, with each entry carrying its own task, session, artifact reference, and reported connection status. The stream provides a direct selected-preview route and a labeled return path; sequence does not imply causal relationship or preview provenance.

  • Show five saved Runs as dated entries in a single chronological stream, each with Run identity, task, session, artifact reference, and connection status.
  • Allow a reader to open a Run's detail inline, with all identity fields repeated in the expanded entry.
  • Offer a separate selected-preview link and a return link to the stream; after return, expose Run identifiers for reidentification.
  • Present a design review route with shared criteria, evidence, recommendation, alternatives, and unknowns.

3

案内フロー / Guided record inspection with explicit checkpoints

A focused inspection flow guides a reader through locating one of five saved Runs, checking its associated fields and reported connection status, and optionally opening a separately selected preview before returning to reidentify the record. The flow organizes inspection steps without implying that the saved focus is restored.

① Run を探す
② 対象を調べる
③ 別の Preview を開く
仕組みと境界を見る
  • Use a focused task flow: locate one of five saved Runs, inspect task/session/artifact reference and connection status, optionally open the selected preview, then return and reidentify from visible fields.
  • Present one Run at a time in a focused detail panel, with a step indicator for location, inspection, and optional preview return.
  • Label the preview as separately selected and provide a return-to-monitor control; make no claim of restored selection or scroll position.
  • Provide a separate review route where structurally different options share criteria, evidence, recommendation, alternatives, and unknowns.
