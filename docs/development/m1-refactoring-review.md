## Preserved observable contracts

This change does not edit code, schemas, manifests, fixtures, tests, configuration, lockfiles, or CI. In particular, the following remain the acceptance boundary:

- `@mimic/core` exports and the CLI's ESM package/bin entry points; the bare CLI readiness JSON and documented flags, compact stdout, stderr diagnostics, and exit codes.
- Artifact schema versions, canonical JSON and SHA-256 digest bytes, deterministic YAML handling, append-only exact revisions, dependency locks, readback verification, and on-disk snapshot/workspace formats.
- Run-state precedence and transitions, idempotent retry identifiers, Decision Packets and Records, exact named Human Commit Point publication, ordering, and unchanged historical revisions.
- Scope, provenance, policy, Skill-routing, local-confirmation, and signed-receipt authority checks, including fail-closed outcomes and protected trust-root handling.
- Test discovery, cases, assertions, fixtures, CI checks, human gates, and the separation of repository contributor instructions from runtime reasoning Skills.

There is no moved-path mapping because no path moves. No API, security policy, package dependency architecture, or product behavior is intentionally changed.
